# Original game logos

The menu uses the original game wordmarks, archived by LaunchBox Games Database.
The PNGs are copied without redrawing, recoloring, cropping, or changing transparency.
Android displays them with FIT_CENTER to preserve their proportions.
Unreal and Unreal Tournament branding belongs to Epic Games.
